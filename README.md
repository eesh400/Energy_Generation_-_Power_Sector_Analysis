# Energy Generation & Power Sector Analysis

## Overview

This project analyses trends in the power sector using six years of energy data from 2019 to 2024.

The analysis focuses on electricity generation by fuel type, changes in generation patterns, installed capacity, and power-sector emissions. Excel PivotTables and visualisations are used to identify trends and compare the contribution of different energy sources over time.

## Objectives

- Analyse electricity generation trends from 2019 to 2024
- Compare electricity generation across different fuel types
- Examine changes in the energy generation mix over time
- Analyse trends in installed power capacity
- Examine power-sector emissions and CO₂ intensity
- Identify major changes and trends within the power sector

## Key Analysis

### 1. Electricity Generation Analysis

Analysed electricity generation in GWh across different fuel sources from 2019 to 2024.

The analysis compares the contribution of major generation sources and highlights changes in the generation mix over the six-year period.

### 2. Energy Generation Mix

Compared generation from different fuel categories to understand:

- Which sources contributed most to electricity generation
- Changes in the contribution of individual fuel types
- Growth or decline in generation across the period
- Overall changes in the power generation mix

### 3. Power Capacity Analysis

Analysed changes in installed electricity generation capacity across different energy sources.

### 4. Power Sector Emissions

Examined power-sector emissions and related indicators, including CO₂ intensity, to provide additional context for changes in electricity generation.
